# بوت مكافآت تلغرام — مهام ودولاب حظ

بوت عربي جاهز للنشر على **Railway**، مع لوحة تحكم كاملة للأدمن وقاعدة بيانات SQLite. لا تحتاج إلى تعديل أي ملف برمجي: أضف فقط توكن البوت وTelegram ID الخاص بالأدمن.

## المزايا المنفذة

| القسم | ما يقدمه البوت |
| --- | --- |
| شاشة البداية | ثلاثة أزرار رئيسية: **المهام**، **دولاب الحظ**، **أرباحي**، ولوحة أدمن تظهر للأدمن فقط. |
| المهام | قائمة عريضة وواضحة بكل المهام، مع حالة `مكتملة / غير مكتملة` لكل مستخدم. |
| مهمة القناة | زر اسم المهمة يفتح القناة مباشرة. بعد العودة يضغط المستخدم زر تسجيل التنفيذ، من دون أي فحص لعضوية القناة. |
| دولاب الحظ | لا يُفتح إلا بعد إكمال المهام، ولكل مستخدم **لفتان فقط**. يظهر نرد Telegram ورسالة تشويقية قبل النتيجة. |
| النتائج | يحدد الأدمن نتيجة كل لفة بالاختيار من المستخدمين أو بإدخال Telegram ID يدويًا حتى لو لم يبدأ المستخدم البوت. أي لفة لم يحددها الأدمن نتيجتها الافتراضية «حظ أوفر». |
| أرباحي | سجل دائم لجميع نتائج اللفات المنفذة للمستخدم. |
| لوحة الأدمن | إضافة/إزالة المهام، إضافة/إزالة الجوائز، إحصاءات، قائمة المستخدمين، وتحديد نتيجة كل لفة. |
| إيقاف التسجيل | زر **منع المستخدمين الجدد**؛ المستخدمون القدامى يبقون قادرين على استعمال البوت، والجديد تصله رسالة أن البوت موقوف. |
| الحفظ | جميع البيانات تُحفظ في SQLite، ويجب ربط Railway Volume كي لا تضيع بعد إعادة النشر. |

> **تنبيه عن الألوان:** Telegram لا يدعم ألوانًا برمجية حقيقية لأزرار البوت العادية. لذلك استُخدمت رموز وأيقونات لونية واضحة (🟦، 🎡، 💰، ✅، 🚫) مع ترتيب احترافي. الألوان الحقيقية تتطلب Telegram Web App، وهو منتج مختلف عن أزرار البوت التقليدية.

## 1) أنشئ البوت واستخرج البيانات المطلوبة

1. افتح [@BotFather](https://t.me/BotFather) في تلغرام.
2. استخدم الأمر `/newbot`، ثم انسخ **Bot Token**.
3. اعرف رقم حسابك الرقمي (**Telegram ID**) عبر [@userinfobot](https://t.me/userinfobot) أو أي بوت موثوق لإظهار المعرّف.
4. لا تشارك التوكن مع أي شخص ولا تضعه في GitHub.

المتغيرات الوحيدة المطلوبة:

```env
BOT_TOKEN=توكن_بوت_فاذر_هنا
ADMIN_IDS=رقم_تلغرام_الأدمن
```

- لإضافة أكثر من أدمن: `ADMIN_IDS=111111111,222222222`
- لا تضع `DATABASE_PATH` على Railway عند اتباع خطوة الـVolume أدناه.

---

## 2) النشر على Railway

### الطريقة الموصى بها: GitHub ثم Railway

1. أنشئ مستودع GitHub جديدًا وارفع **كامل هذا المجلد** إليه.
2. افتح [Railway](https://railway.app) واختر **New Project** → **Deploy from GitHub repo**.
3. اختر المستودع. سيكتشف Railway ملف `requirements.txt` و`railway.toml` تلقائيًا.
4. من **Variables** داخل خدمة Railway، أضف:
   - `BOT_TOKEN` = توكن البوت
   - `ADMIN_IDS` = Telegram ID الخاص بك
5. من الخدمة نفسها، افتح **Volumes** وأنشئ Volume جديدًا ثم اربطه بمسار:

   ```text
   /data
   ```

6. أعد النشر أو انتظر اكتمال النشر. سيبدأ البوت عبر Long Polling ولا يحتاج دومين أو Webhook.
7. افتح البوت في Telegram وأرسل `/start`.

### فحص أن النشر نجح

في سجلّات Railway يجب أن ترى سطرًا شبيهًا بـ:

```text
Bot started. Administrators: 123456789
```

إذا ظهر خطأ `BOT_TOKEN is missing` أو `ADMIN_IDS is missing`، راجع المتغيرات في Railway ثم أعد النشر.

> **مهم:** وجود الـVolume على `/data` ضروري جدًا. من دونه ستُمسح قاعدة البيانات عند إعادة بناء الخدمة أو إعادة النشر، وتضيع المهام والمستخدمون والنتائج.

## 3) التشغيل محليًا (اختياري)

يتطلب Python 3.11 أو أحدث.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# ضع BOT_TOKEN و ADMIN_IDS داخل ملف .env
python -m bot.main
```

قاعدة البيانات المحلية تُنشأ تلقائيًا في `data/rewards_bot.db`.

## 4) استعمال لوحة الأدمن

بعد تشغيل البوت من الحساب الذي رقمه موجود في `ADMIN_IDS`:

1. أرسل `/start`.
2. اضغط **🛠 لوحة الأدمن** أو أرسل `/admin`.
3. لإضافة مهمة: **إضافة مهمة** → اكتب اسمها → أرسل رابط القناة، مثل `https://t.me/my_channel` أو `t.me/my_channel` أو `@my_channel`. تقبل المهام أيضًا روابط الدعوة الخاصة بصيغة `https://t.me/+...`.
4. لإضافة جائزة جاهزة: **إضافة جائزة** → الاسم → الوصف أو رابط الاستلام.
5. لتحديد النتيجة: استخدم **عرض المستخدمين** لاختيار مستخدم مسجل، أو **تحديد نتيجة عبر Telegram ID** لإدخال المعرّف مباشرة حتى لو لم يبدأ المستخدم البوت. ثم اختر نتيجة اللفة الأولى أو الثانية:
   - اختر جائزة محفوظة، أو
   - اضغط **كتابة نتيجة مخصصة** وأرسل مثلاً:

   ```text
   مبروك! ربحت بطاقة فيزا بقيمة 10$
   رابط استلام المكافأة: https://example.com/reward
   ```

6. استخدم **منع المستخدمين الجدد** عند إغلاق الاستقبال. يمكن فتحه لاحقًا من الزر نفسه.

### ملاحظات تشغيلية

- يمكن للأدمن تخصيص نتيجة أي لفة. اللفات التي لا يخصصها تكون «حظ أوفر» تلقائيًا، بحد أقصى لفتين.
- يمكن تجهيز نتائج لاعب عبر Telegram ID قبل أن يبدأ البوت. عندما يفتح اللاعب البوت لاحقًا، تُستخدم النتائج المحددة له. لا يستطيع البوت إرسال رسالة خاصة إلى لاعب لم يبدأ محادثة البوت بعد.
- لا يمكن تعديل نتيجة لفة تم تنفيذها بالفعل، لحماية سجل الأرباح.
- يمكن حذف مهمة أو جائزة من اللوحة دون حذف السجل التاريخي للنتائج السابقة.
- زر رابط القناة يفتحها فور الضغط عليه من قائمة المهام. بعد الرجوع إلى البوت يضغط المستخدم زر «سجّل تنفيذ المهمة». Telegram لا يتيح لزر الرابط أن يفتح الرابط ويرسل للبوت إشارة إتمام في نفس النقرة؛ لذلك زر تسجيل الإتمام منفصل. لا يفحص البوت عضوية القناة.

## هيكل المشروع

```text
telegram-rewards-bot/
├── bot/
│   ├── config.py       # قراءة المتغيرات
│   ├── db.py           # قاعدة SQLite والمعاملات الآمنة
│   ├── handlers.py     # واجهة المستخدم ولوحة الأدمن
│   ├── main.py         # تشغيل Long Polling
│   └── states.py       # خطوات إدخال الأدمن
├── tests/
│   └── test_database.py

├── Procfile
├── railway.toml
└── requirements.txt
```

## اختبار المشروع

```bash
pip install -r requirements.txt pytest
PYTHONPATH=. pytest -q
```

## أمان

- لا ترفع ملف `.env` إلى GitHub.
- لا تعطِ أحدًا `BOT_TOKEN`.
- اجعل `ADMIN_IDS` لأرقام الأشخاص المخولين فقط.
- لا يوجد في المشروع أي تحقق عضوية بالقنوات أو أي جمع لبيانات حساسة خارج معلومات Telegram المتاحة للبوت (المعرف والاسم واسم المستخدم).
